# 🏥 City Hospital - Hospital Management Portal (MVP Prototype)

A clean, modern, and uncluttered hospital portal built for your class project presentation with demo data and zero external database dependencies.

---

## 🌟 Key Layout & Features

1. **Hospital Name:** **City Hospital**
2. **Direct Access:** Patients view all hospital info immediately upon opening the website.
3. **Left Panel Navigation:**
   - 🏥 **Hospital Info:** Address, visiting hours, OPD hours, insurance desk.
   - 👨‍⚕️ **Doctor Availability:** Real-time doctor duty status (`Available`, `In OPD`, `In Surgery`, `Off Duty`), consultation room numbers, OPD timings, and token generator.
   - 🛏️ **Bed Availability:** Bed counts and live status tags for ICU, General, Semi-Private, Deluxe, and Emergency wards.
   - 🩺 **Offered Procedures:** Catalog of medical & surgical procedures (Cardiology, Orthopedics, General Surgery, Neurology, Pulmonology) with recovery estimates.
   - 📋 **Admission Procedures:** Planned vs Emergency admission steps + required documents checklist.
   - 🚨 **Emergency Contact:** 24/7 hotline numbers and ambulance service.
4. **Staff Login (Top-Right Corner):**
   - Clean **"Staff Login"** button in top right.
   - Demo credentials: `admin` / `hospital123` (or click **Autofill**).
   - Staff can change doctor statuses and toggle bed occupancy (Free vs Occupied).
   - All changes immediately sync and display on the website!
